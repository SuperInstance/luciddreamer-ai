# LucidDreamer

> Dream journal with lucid practice tracking.

**[luciddreamer.ai](https://luciddreamer.ai)**

A dream journal that actually makes you better at remembering. Voice-log your dreams in the morning haze, tag recurring themes, and track your lucid practice. No crystals required.

## What It Does

- **Voice logging** — Half-asleep? Hold the button, mumble your dream. Transcribed and timestamped automatically
- **Theme detection** — Recurring locations, people, and symbols highlighted automatically
- **Lucid practice tracker** — Log reality checks, WBTB attempts, and results. See which techniques work for you
- **Session recaps** — Each dream entry tagged with location, themes, and lucid status
- **Technique guides** — Built-in reality testing, WBTB, and MILD instructions

## Tech Stack

- Cloudflare Workers (edge deployment)
- Single-file HTML response
- Custom domain via Cloudflare
